Smoke tests, 2026-11-11


Run on preview against stock item 325 (SKU B6F, 7 on hand) and its Listing, "Large 36x28mm Uranium Glass Cabochon Vintage Green Floral Pressed Glass 1930s Czech". Every change was restored, and the count reads 7 again. No real Etsy quantity was changed: marketplace sync is off (live: false) and no stock item is linked to an Etsy listing yet, so every push is a dry run.


Fixed locally, not deployed: the listing check reported false failures. It says the category "Craft Supplies & Tools < Beads, Gems & Cabochons < Cabochons" matches no Etsy node and that the section "Uranium Gems and Cabs" does not exist. Both names came from Etsy, and both are stored as clean text. The cause is in marketplace/sync.js etsyPlan, which asks Etsy for its categories and sections only if (live || env.ETSY_SHOP_ID). With sync off and no shop id set, both stay empty, so every check fails these two lines. The fix asks Etsy on every check, through the same ten-minute cache the import uses, and when Etsy cannot be reached it says so instead of calling a real category or section missing. A test covers both cases. It is uncommitted and not yet on preview. That preview has no ETSY_SHOP_ID is inferred from this result and was not read from the environment.

Not exercised: pulling real sales from Etsy (/api/marketplace/sales/pull). With sync off, it permanently records each order it cannot match as "no stock item", so it was left alone. A Listing reads its quantity from stock by SKU at push time and stores no copy, so the Listing side follows stock without a separate write. That is verified from translate.js, not observed on Etsy. An earlier run of the script misread the starting count and set B6F to 0; it was repaired to 7 and the run repeated. The item's movement log keeps those entries, each noted "Smoke test".



To settle before this becomes the function


    
  
  1. SKUs. eBay keys every item and offer by SKU, and none of the 608 imports has one. Recommend generating them from the Listing plus option (for example VINE-R-7.5) and linking them to Stock Items in one pass.
    2. 
  
  2. Category map. Etsy's taxonomy and eBay's category tree differ. Recommend one table from Etsy path to eBay category id, so a whole Etsy section maps at once rather than listing by listing.
    3. 
  
  3. Condition default. Handmade new work is NEW. Recommend a shop default, with a per-listing override for vintage pieces.
    4. 
  
  4. Item specifics from Etsy values. Etsy materials and the variation name can fill eBay aspects (Metal, Ring Size). These are the rows where pointing one value at another pays off most.
    5. 
  
  5. eBay title. eBay stops at 80 characters, Etsy at 140. This example fits (55), but long titles need the eBay title override.
